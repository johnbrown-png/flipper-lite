# Unavailable Video Replacement Workflow

## Overview
The Improve Pick QA GUI now integrates with video availability checking to enable systematic replacement of unavailable videos (deleted/private or embedding-disabled).

## Features

### 1. **Automatic Availability Report Loading**
- Loads `reports/unavailable_video_availability_check.csv` on startup
- Silently fails if report doesn't exist (no disruption to existing workflow)
- Updates availability state whenever the report is regenerated

### 2. **Visual Highlighting in Current Picks Panel**
- **RED background (#ffcccc)**: ❌ Deleted or private videos (critical - must replace)
- **YELLOW background (#fff9cc)**: 🚫 Embedding-disabled videos (decision needed)
- Emoji prefixes provide at-a-glance identification
- Applied to video title, channel, and score labels for clear visibility

### 3. **Navigation Controls**
**"Jump to Next Unavailable Video" button:**
- Navigates to next small step with unavailable videos
- Respects current filter settings
- Wraps around to beginning if at end
- Shows informative message if no affected steps found

### 4. **Filtering Controls**
**"Show unavailable only" checkbox:**
- When enabled, filters dropdown to only show affected small steps
- Progress indicator shows count of affected steps

**Filter type checkboxes:**
- "Deleted/private" - Include truly unavailable videos (default: ON)
- "Embedding-disabled" - Include videos that won't embed (default: OFF)
- Allows focusing on critical replacements first

### 5. **Status Summary Display**
**Red warning label (Row 2 of selector frame):**
- Shows counts for current small step
- Format: `⚠️ ❌ 2 deleted/private | 🚫 1 embedding-disabled`
- Only visible when current step has unavailable videos
- Updates automatically when navigating between steps

## Workflow

### Phase 1: Replace Critical Videos (Deleted/Private)
1. Run `check_video_availability.bat` to generate latest report
2. Launch Improve Pick GUI via `launch_improve_pick_gui.bat`
3. Check "Show unavailable only" filter
4. Ensure "Deleted/private" is checked, "Embedding-disabled" is unchecked
5. Click "Jump to Next Unavailable Video"
6. Review RED highlighted videos in Current Picks panel
7. Use existing search/candidate selection to find replacements
8. Click "Add to Delete Queue" for unavailable videos
9. Update QA CSV with new picks
10. Repeat until all deleted/private videos are replaced

### Phase 2: Review Embedding-Disabled Videos (Optional)
1. Check "Embedding-disabled" filter
2. Click "Jump to Next Unavailable Video"
3. Review YELLOW highlighted videos
4. Decide whether to replace or keep (still viewable on YouTube.com)
5. For JoAnn's School videos: consider finding alternative channels or keeping as-is

## Integration Points

### New Instance Variables
```python
self.unavailable_videos: dict[str, dict]  # {video_id: {status, source_step, source_position}}
self.show_unavailable_only_var: BooleanVar
self.filter_deleted_var: BooleanVar
self.filter_embedding_var: BooleanVar
self.availability_summary_var: StringVar
self.all_step_options: list[str]  # Unfiltered dropdown options
```

### New Methods
- `_load_availability_report()` - Load CSV data on startup
- `_step_has_unavailable_videos(step_id)` - Check if step has issues
- `_jump_to_next_unavailable()` - Navigation logic
- `_on_filter_unavailable_changed()` - Filter dropdown updating
- `_extract_step_id_from_label(label)` - Parse dropdown labels
- `_update_availability_summary_for_step(step_id)` - Update status display

### Modified Methods
- `__init__()` - Added new instance variables and UI controls
- `_load_initial_data()` - Calls `_load_availability_report()`
- `_on_step_selected()` - Calls `_update_availability_summary_for_step()`
- `_populate_precomputed()` - Added visual highlighting with emoji + background colors
- `_refresh_step_combo_labels()` - Stores unfiltered options in `self.all_step_options`
